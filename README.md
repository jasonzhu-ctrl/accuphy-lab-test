# Accuphy Lab — test pages

Built pages of the Accuphy Lab 3D sonar lake, for friends and ad tests. The source lives in a private repository;
this repository only holds the built pages (rebuilt there with `node scripts/build-share.mjs`).

- `/` — PingLive + PingLive Mini
- `/mini/` — PingLive Mini only

Both pages are unlisted: `noindex` and `robots.txt` keep them out of search engines; only people with the link see them.
